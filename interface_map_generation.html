1 Map Generation

Overview

In this workflow, the user produces a Land Use and Land Cover (LULC) map. Each step is presented as a panel on the left of the map canvas and progresses via the indicator at the top of the panel. To ensure usability regardless of technical know-how, user cannot skip steps; each step unlocks the next only after the required input has been provided by the user and the Geospatial Engine (GE) confirms the corresponding output has been produced and saved.

Step 1: Basic Information

Overview

Provides the inputs needed before any geospatial computation: where to map, when, and from which satellite imagery source.

Step 1.1: Geographic Area

Overview

This is the first required input in the Map Generation workflow where the user specify the geographic area they want to map by choosing one of three methods available: upload, draw area, or select an administrative boundary.

Step 1.1.a: Upload Area

Overview

The user uploads a polygon file to define the geographic boundary of the area they want to map.

User Input to Interface

  1. The user uploads their own AOI file in .zip format that should include all required shapefile components (.shp, .shx, .dbf, .prj). The system also supports uploads of .kml or .kmz files.

  2. The user chooses a spatial resolution from the selections (10 m x 10 m, 30 m x 30 m, 100 m x 100 m, 500 m x 500 m, or 1 km x 1 km).

Process

  1. The user can upload their own AOI file in .zip format that includes all required shapefile components (.shp, .shx, .dbf, .prj).

  2. The system checks on all required shapefile components that needs to be put in the .zip file. The system also supports uploads of .kml or .kmz files.

    NoteSuccess Notification

    If all shapefile components pass validation, continue to Process 3

    ImportantError Handling Notification

    If the shapefile components do not match, an error warning is displayed: ’No .shp file found in the .zip file.’

  3. The system retrieves AOI file information.

    NoteSuccess Notification

    If all file information is correct, continue to Process 4

    ImportantError Handling Notification

    If the file information cannot be found, an error warning is displayed: ’AOI not found’

  4. The system retrieves AOI file area size information.

    NoteSuccess Notification

    If the area size information is within the maximum area allowed, continue to Process 5

    ImportantError Handling Notification

    If the area size information is too large, an error warning is displayed: ’Draw area exceeds maximum limit’

  5. The system validates the geometry of the AOI for both .shp and .kml using the shapefile_validator functions.

    NoteSuccess Notification

    If GIS file completeness is validated, continue to Process 6

    ImportantError Handling Notification

    If validation failed, an error warning is displayed: ‘Geometry validation failed.’

  6. The system returns the validated and processed shapefile.

    NoteSuccess Notification

    The system shows a confirmation when the AOI is loaded successfully by showing a purple box with ‘Approximate size of your mapping area: X [number] Ha’ displayed

  7. The system activates the next step.

  8. The user chooses a spatial resolution selection (10 m x 10 m, 30 m x 30 m, 100 m x 100 m, 500 m x 500 m, or 1 km x 1 km).

  9. The system returns the validated and processed shapefile.

    NoteSuccess Notification

    The “Confirm” button is activated

  10. If the user clicks “Reselect Area”, the uploaded file is deleted.

    NoteSuccess Notification

    All inputs are being reset, the user will be redirected to Step 1: Basic Information

Step 1.1.b: Draw Area

Overview

The user draws their area of interest directly on the map by creating borders of area they want to map. Each click adds a new side/edge (vertex) to the polygon, with a double-click to finish drawing and close the polygon. This is useful when the user does not have a prepared polygon file or wants to quickly define a simple area.

User Input to Interface

  1. The user creates a series of clicks on the map to create a polygon.

  2. The user chooses a spatial resolution from the selections (10 m x 10 m, 30 m x 30 m, 100 m x 100 m, 500 m x 500 m, or 1 km x 1 km).

Process

  1. The user creates a polygon by clicking on the map.

  2. The system retrieves the AOI area size information.

    NoteSuccess Notification

    The system shows a confirmation when the AOI is loaded successfully by showing a purple box with ‘Approximate size of your mapping area: X [number] Ha’ displayed

    ImportantError Handling Notification

    If the area size information is too large, an error warning is displayed: ’Draw area exceeds maximum limit’

  3. The system activates the next step.

  4. The user chooses a spatial resolution selection (10 m x 10 m, 30 m x 30 m, 100 m x 100 m, 500 m x 500 m, or 1 km x 1 km).

  5. The system returns the validated and processed shapefile.

    NoteSuccess Notification

    The “Confirm” button is activated

  6. If the user clicks “Reselect Area”, the drawn polygon is deleted, and the user will be redirected to Step 1: Basic Information.

    NoteSuccess Notification

    All inputs are being reset, the user will be redirected to Step 1: Basic Information

Step 1.1.c: Administrative Boundaries

Overview

The user selects the area they want to map based on a drop down list of Indonesian regency administrative boundaries. Disclaimer about the data source (Badan Informasi Geospasial) is included with the data uploaded as GEE asset and the link provided and shared publicly. The system provides a preview of the selected boundary.

User Input to Interface

  1. The user selects an AOI based on a drop down list of Indonesian regency administrative boundaries.

  2. The user chooses a spatial resolution from the selections (10 m x 10 m, 30 m x 30 m, 100 m x 100 m, 500 m x 500 m, or 1 km x 1 km).

Process

  1. The user selects an administrative boundary from the drop down list.

  2. The system retrieves the AOI information from the selected administrative boundary selections.

  3. The system provides the name of selected administrative boundary.

  4. The system activates the next step.

  5. The user chooses a spatial resolution selection (10 m x 10 m, 30 m x 30 m, 100 m x 100 m, 500 m x 500 m, or 1 km x 1 km).

  6. The system runs the related functions in AOI from Indonesia Administrative Boundaries and provides a polygon of the selected boundary on the map canvas.

    NoteSuccess Notification

    The “Confirm” button is activated

  7. If the user clicks “Reselect Area”, the selected administrative polygon is deleted, and the user will be redirected to Step 1: Basic Information.

    NoteSuccess Notification

    All inputs are being reset, the user will be redirected to Step 1: Basic Information

Step 1.2: Time Period

Overview

The user defines the time period for the land use and land cover map. Currently available options for time interval of the satellite imagery period are limited to yearly (a single year) or custom date range.

User Input to Interface

  1. The user selects the time interval they want to use (yearly or custom date range).

  2. The user further specifies the period by selecting the year (if yearly) or entering the start and end dates (if custom date range) that they want to map.

Process

  1. The user chooses a time interval selection “By year” or ”Custom date range”.

  2. The system provides input fields to specify time period based on selected time interval.

  3. If “By year”: The system shows the year selections from 1972 until current year in a form of a drop down list.

  4. If “Custom date range”: The system provides calendar display to allow user choose specific start and end dates.

  5. The user selects a year selection (1972–current year) or specific start and end dates.

  6. The system activates “Set time period” button.

  7. If the user clicks “Set time period” button, the system confirms the time period input.

    NoteSuccess Notification
    • The system shows a confirmation by showing a purple box with a summary of: time interval, period, satellite imagery date range selected
    • A clickable “Change input” text also appears

  8. If the user clicks “Change input” button, the system resets all input from Step 1.2: Time Period and is brought back to the beginning of Step 1.2: Time Period.

Step 1.3: Satellite Imagery

Overview

The user confirms default selection for satellite imagery source and the maximum cloud coverage percentage or click change input to customize final input to the basic information.

User Input to Interface

  1. Most recent available satellite imagery source and 30% maximum cloudy area are chosen as default input. User is provided with the option to “Change input”. If chosen, user can input 2 and 3 below.

  2. The user selects the satellite imagery source from a drop down list.

  3. The user selects the maximum cloudy area by dragging the slider to the desired number.

Process

  1. The system adjusts default satellite imagery source and other options according to time period input in Step 1.2: Time Period.

  2. The user sets a preferred cloud cover threshold, if none chosen, the default value of 30% is used.

  3. The system performs pre-processing functions in Satellite Data Acquisition and Filtering.

    NoteSuccess Notification

    When all information is collected, continue to Process 4

    ImportantError Handling Notification

    The system provides an error notification if no satellite images were found based on the user’s parameter. The user is prompted to change the cloud cover threshold or change the time period.

Step 1.4: Confirm and Preview

Overview

After all input to basic information have been finalized, user is presented with summary of input for final confirmation. User confirms through clicking “View satellite imagery” which will trigger the system to retrieve all available scenes, removes cloudy pixels, and combines the rest into a single cloud-free composite image. This composite is the base image for all classification steps. Three visualisation modes are generated: True Colour (RGB), False Colour Infrared, and Land/Water.

User Input to Interface

  1. The user clicks Next to confirm summary of all inputs after Step 1.3: Satellite Imagery.

  2. The user clicks View satellite imagery to initiate processing of satellite imagery.

Process

  1. The system summarizes the basic information from previous steps.

    NoteSuccess Notification

    The user’s input summary is displayed in a purple box, showing:

    • Mapping area: approximate size of your mapping area
    • Time period selected: time interval, selected period, satellite input date range
    • Satellite imagery: satellite imagery source, maximum cloudy area

    Two buttons appear:

    • “Change Input”; continue to Process 2
    • “View Satellite Imagery”; continue to Process 5
    ImportantError Handling Notification

    The system provides an error notification if no satellite images were found based on the user’s parameter. The user is prompted to change the cloud cover threshold or change the time period.

  2. If the user clicks on the “Change Input” button, “Edit” (pencil icon) buttons appear next to each of the input summary’s heading. Once clicked, a pop up window appeared for user to choose:

    • “Change Input”, continue to Process 3, or

    • “Discard Changes”, continue to Process 4.

  3. If the user clicks on the “Change Input” button in the pop up window, all inputs are being reset, back to the beginning of Step 1: Basic Information.

  4. If the user clicks on the “Discard Changes” button in the pop up window, the panel still displays the user’s input summary. “Cancel Change” button appear, while “View Satellite Imagery” is disabled. Once the “Cancel Change” button is clicked, back to Process 1.

  5. If the user clicks on the “View Satellite Imagery” button, the system processes the satellite image request.

    NoteSuccess Notification
    • A table of Generated Composite of Imagery Obtained appeared under the User’s Input Summary along with Cloud Coverage Statistic.
    • Composite of satellite imagery appears on the base map, with default setting of true colour (RGB).
    • Layers option appears on the bottom right corner of the screen, includes:
      • Mapping area; with polygon toggle
      • Composite of satellite imagery; with true colour (RGB), false colour infrared (NIR/Red/Green), land/water (NIR/SWIR1/RED) toggle options
      • LULC class; still disabled in this step
    • User can then download the composite, leading to Process 6.
    • “Next” button appears, which leads to Step 2: Land Use and Land Cover Classification.

  6. If the user downloads composite, a .zip file containing satellite image composite is downloaded to user’s local device.

Step 2: Land Use and Land Cover Classification

Overview

The user defines the land use and land cover classes that will be mapped. There are two main options: using the built-in Luma default classification scheme or uploading a custom classification scheme. The selected classes determine which training data will be used in the next step. The Epistem-AI feature will also be available here.

Step 2.1: Land Use & Land Cover Classification Scheme

Overview

Luma supports user-defined classification schemes and default classification or templates for commonly used classification schemes.

Step 2.1.a: Own Classification

Overview

The user creates their own classification scheme manually or by uploading a file.

User Input to Interface

  1. The user clicks Own Classification to create their own classification scheme.

Process

  1. The user clicks “Own Classification”.

  2. The system shows two options within the Own Classification window: Manual Input and Upload Classes.

  3. “Manual Input” and “Upload Classes” panels activated.

Step 2.1.a.1: Manual Input

Overview

The user inputs the land use and land cover classes they want to map. They need to type a class name and optionally pick a colour for each class.

User Input to Interface

  1. The user clicks “Add Class” button.

  2. The user fills out LULC class name and selects class color.

Process

  1. The user enters LULC class name and pick a colour out of 28 colour options.

  2. The system stores each class entry individually as it is added.

  3. The system validates class ID, name, and checks for uniqueness with the functions in User Entering the Classification Manually.

    NoteSuccess Notification
    • All added classes are displayed in the class recorded table for preview
    • Upload Classes option still available; if clicked, continue to Step 2.1.a.2: Upload Classes Process 1
    • Confirm LULC Class enabled; once clicked, all inputs are locked and a summary table is previewed, along with three options:
      • “Edit” (pencil icon); continue to Process 4
      • “Download LULC classes (CSV)”; a .csv file containing the inputted classification scheme is downloaded to user’s local device.
      • “Next”; continue to Process 5
    ImportantError Handling Notification

    The system returns a validity flag with an error message if invalid

  4. If the user edits or deletes the classes in the summary table preview, the system stores each class entry individually as it is added and runs the functions in User Entering the Classification Manually.

    NoteSuccess Notification
    • Each class row can be edited individually
    • New classes can be added with Add Class button
    • If all classes are deleted, back to the beginning of Step 2: Land Use and Land Cover Classification
    • “Done” button appears; if clicked:
      • “Next” button appears; continue to Process 5
      • “Download LULC classes (CSV)” appears; a .csv file containing the inputted classification scheme is downloaded to user’s local device
    ImportantError Handling Notification

    The system returns a validity flag with an error message if invalid

  5. If the user clicks on the “Next” button, the user will be directed to Step 3: Mapping Sample Data.

  6. If the user clicks on the “Back” (chevron) button, the panel of Step 1.3: Satellite Imagery Process 8 is being shown. The user has to click the “Next” button to go back to the last edited panel in Step 2: Land Use and Land Cover Classification.

Step 2.1.a.2: Upload Classes

Overview

The user downloads a classification template .csv file and uses it to list the land use and land cover classes they want to map. After filling the template, they need to upload the file to be used as the custom classification scheme.

User Input to Interface

  1. The user clicks “Upload Classes” button.

  2. The user uploads the .csv file containing the classification scheme information containing at least three columns: a class ID (numeric identifier), a class name, and an optional hex colour code specifying the display colour for each class.

Process

  1. The user downloads the .csv file containing the classification scheme information template into the user’s local device.

  2. The user uploads the .csv file containing the classification scheme information.

  3. The system stores the file uploaded and runs the functions in User Uploading Their Own Classification Scheme.

    NoteSuccess Notification

    If the classification scheme file successfully uploaded:

    • A purple box indicating the uploaded file with its file size appears

    • A summary table of recorded classes with its ID number and colour class appears

    • Manual Input option still available; if clicked, continue to Step 2.1.a.1: Manual Input Process 3

    • Confirm LULC Class enabled, if clicked, a summary table is previewed, along with three options:

      • “Edit” (pencil icon); continue to Process 4
      • “Download LUCL classes (CSV)”; a .csv file containing the inputted classification scheme is downloaded to user’s local device.
      • “Next”; continue to Process 5
    ImportantError Handling Notification

    The system returns a validity flag with an error message if invalid

  4. If the user clicks on the “Edit” button, each class row can be edited individually. The uploaded file can be deleted, if clicked, all inputs are being reset, back to the beginning of Step 2: Land Use and Land Cover Classification.

  5. If the user clicks on the “Next” button, the user will be directed to Step 3: Mapping Sample Data.

  6. If the user clicks on the “Back” (chevron) button, the panel of Step 1.3: Satellite Imagery Process 8 is being shown. The user has to click the “Next” button to go back to the last edited panel in Step 2: Land Use and Land Cover Classification.

Step 2.1.b: Default Classification

Overview

The user activates class options from default Luma land use and land cover classification scheme. The user is given the option to choose only a specific subset of the default classes, rather than being required to utilize the entire set.

User Input to Interface

  1. The user clicks Default Classification to use Epistem classification scheme.

  2. The user selects LULC classes from the existing classification scheme.

Process

  1. The user selects subsets of the default classes.

  2. The classification table is being saved to the system.

  3. The system loads the selected classes from a dataset by running functions in User Selecting a Default Classification Scheme.

    NoteSuccess Notification
    • A summary table of recorded classes with its ID number and colour class appears
    • Two buttons appear:
      • “Reset classification”; continue to Process 4
      • “Next”; continue to Process 5

  4. If the user clicks on “Reset classification”, All inputs are being reset, back to the beginning of Step 2: Land Use and Land Cover Classification.

  5. If the user clicks on the “Next” button, the user will be directed to Step 3: Mapping Sample Data.

  6. If the user clicks on the “Edit” button, all inputs are being reset, back to the beginning of Step 2: Land Use and Land Cover Classification.

  7. If the user clicks on the “Back” (chevron) button, the panel of Step 1.3: Satellite Imagery Process 8 is being shown. The user has to click the “Next” button to go back to the last edited panel in Step 2: Land Use and Land Cover Classification.

Step 3: Mapping Sample Data

Overview

The user prepares the sample data for land use and land cover classification in their mapping area. The user can upload existing data or create samples directly in Luma through on-screen sampling. In this step the Sample Data Summary selected in the previous step is also shown. The spectral separability of LULC classes is also being assessed in this step using sample data and near-cloud-free satellite imagery. Pairwise class separability is quantified using the Transformed Divergence (TD) method based on pixel-level spectral statistics, using only the spectral data from Step 1: Basic Information.

Step 3.1: Upload Sample Data

Overview

The user uploads their existing sample data in .zip file format.

User Input to Interface

  1. The user uploads a .zip file containing their sample data.

Process

  1. The user uploads the .zip file containing the sample data.

  2. The system checks if there are any .shp file inside the .zip file by running the functions in User Uploads Their Own Class-Labelled Sample Data.

  3. The system returns the preview of the uploaded sample data on the map canvas and table of the uploaded sample data.

    NoteSuccess Notification
    • A purple box indicating the uploaded file with its file size appears with a delete button, if clicked, continue to the beginning of Step 3: Mapping Sample Data
    • A summary table of Sample Data Summary with ID number, LULC class name, colour class, number of samples, and buttons to view each class appears
    ImportantError Handling Notification

    The system provides an error notification if the system fails to conduct the sample data verification, along with the specific message at which step the validation failed

  4. The user clicks on the “Check Score” button to know their sample data quality.

  5. The system provides a selection for Spatial Resolution (m) and Maximum Pixels Per Class. The default value is 100 m and 5000 pixels.

  6. The system conducts the separability analysis by running the functions in 4  Sample Data Quality Analysis.

    NoteSuccess Notification
    • Training Data Quality result appears, with its category (good, weak, or poor) for each class, and highlights which LULC classes require improvement. A data frame containing details of the pairwise separability is also displayed.
    • The user can choose several paths:
      • Delete the uploaded file; all input in Step 3.1: Upload Sample Data is deleted and continue to the beginning of Step 3: Mapping Sample Data
      • On Screen Sampling:
        • Single Point Input; continue to Step 3.2.a.1: Single Point Input
        • Bulk Point Input; continue to Step 3.2.a.2: Bulk Point Input
      • Next; continue to Step 4: Customize Mapping Parameters

  7. If the user clicks on the “Recheck Score” button, continue to Process 5 and 6.

  8. If the user clicks on the “Back” (chevron) button, the panel of Step 2: Land Use and Land Cover Classification summary table of recorded classes is being shown. The user has to click the “Next” button to go back to the last edited panel in Step 3: Mapping Sample Data.

Step 4: Customize Mapping Parameters

Overview

The user can choose a set of predictors that optimize the discrimination of LULC classes in the classification model. Predictors are generated from three principal categories: spectral transformations (indices), terrain-based metrics, and distance-based metrics, capturing complementary spectral, topographic, and spatial information.

Step 4.1: Predictor Selection

Overview

The user is prompted to select the predictors currently supported by Luma Geospatial Engine by using check boxes or upload their own predictor data in .zip file.

Step 4.2.a: Default Predictors

Overview

The user selects the predictors currently supported by Luma Geospatial Engine by using check boxes.

User Input to Interface

  1. The user selects the predictors by using check boxes.

Process

  1. The user selects the predictors from the list.

  2. The system retrieves the predictors based on the user’s selection and runs the functions in Selection of Predictors.

    NoteSuccess Notification
    • “Next” button leads to Summary of LULC List Parameters showing the predictors selected and Random Forest Variable in a purple box.
    • Two buttons appear:
      • “Change Input”; continue to Process 3
      • “Next”; continue to Process 4

  3. The user clicks on “Change Input”.

    NoteSuccess Notification
    • “Change Input”; all inputs being reset and back to the beginning of Step 4: Customize Mapping Parameters
    • “Discard Changes”; stay in Process 3 with “Cancel Change” button activated

  4. If the user clicks on “Next” button, the system generates map with all input from Step 1-4.

Step 4.2: Classification Model Training

Overview

The user is given the option to adjust the classification model by adjusting the value of the Random Forest variable to classify the satellite images into land use and land cover classes using training data. The default value of the Random Forest parameters are 150 number of trees and 1 minimum leaf population. The user is also prompted to define the proportion to split the sample data into training and validation dataset. The default value of the dataset proportion is 70% for training data and 30% for validation data.

Additional Features

Overview

The user can save their land use and land cover mapping progress and share their mapping results by logging in/signing up to an Epistem account. Once logged in, user account is activated on the upper right corner of the screen with the user’s initial or profile picture.

Feature 1: Save Progress

Overview

Once logged in, the user can save their land use and land cover mapping progress, name the map they are working on, and view which steps they have done and where they are currently in. This can be viewed on the upper right corner of the map canvas. The session is stored for up to 24 hours within the database.

Process

  1. The user clicks “Save” button.

  2. The user is prompted to log in or sign up for an Epistem account if they have not already registered.

  3. Once logged in, the user can name the map they are working on in order to save it.

  4. Progress is saved automatically; completed steps and the user’s current position are visible in the top-right corner of the map canvas.

Feature 2: Download Map

Overview

Once logged in, the user can download their generated map.

Process

  1. The user downloads their map.

  2. The system sends an email containing the exported LULC map with a download link.

    NoteSuccess Notification

    The user receives an email from webdev@epistem.io containing a download link to the GeoTIFF of the exported map

Overview

Once logged in, the user can share their generated map to another person with an email address.

Process

  1. The user input recipient’s name and email address.

  2. The system sends and email to the recipient containing the exported LULC map with a download link.

    NoteSuccess Notification

    The recipient receives an email from webdev@epistem.io containing a download link to the GeoTIFF of the exported map
